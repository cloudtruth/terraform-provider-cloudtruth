# cloudtruth_azure_integration (Resource)

A CloudTruth Azure Key Vault integration.

## Important: Manual Setup Required

After creating this resource with Terraform, you **MUST** manually grant the CloudTruth service principal access to your Azure Key Vault. **The integration will remain in "errored" status until you complete this step.**

### Quick Setup Steps:

1. **Find your CloudTruth Service Principal Application ID** (contact your CloudTruth administrator)
2. **Grant Key Vault permissions** using one of these methods:

   **Method A: Azure RBAC (Recommended)**
   - Navigate to your Key Vault → **Access control (IAM)** → **Add role assignment**
   - Role: **Key Vault Secrets Officer** (for writable) or **Key Vault Secrets User** (read-only)
   - Assign to: CloudTruth service principal

   **Method B: Access Policies (Legacy)**
   - Navigate to your Key Vault → **Access policies** → **Create**
   - Permissions: Get, List (+ Set, Delete for writable integrations)
   - Principal: CloudTruth service principal

3. **Verify**: Run `terraform refresh` and check that `status = "connected"`

For detailed step-by-step instructions, see: [AZURE_SETUP.md](https://github.com/cloudtruth/terraform-provider-cloudtruth/blob/main/AZURE_SETUP.md)

## Example Usage

```terraform
# Basic Azure Key Vault integration (read-only)
resource "cloudtruth_azure_integration" "example" {
  vault_name  = "mykeyvault"
  tenant_id   = "12345678-1234-1234-1234-123456789abc"
  description = "Production Azure Key Vault integration"
}

# Azure Key Vault integration with write access and resource tags
resource "cloudtruth_azure_integration" "writable" {
  vault_name  = "mykeyvault"
  tenant_id   = "12345678-1234-1234-1234-123456789abc"
  description = "Writable integration for syncing secrets to Azure"
  writable    = true

  resource_tags = {
    Environment = "production"
    ManagedBy   = "terraform"
    Team        = "platform"
  }
}

# Use the integration with import and push actions
resource "cloudtruth_azure_import_action" "import" {
  integration = cloudtruth_azure_integration.example.name  # Format: "vault_name@tenant_id"
  name        = "Import Azure secrets"
  description = "Import secrets from Azure Key Vault"

  resource             = "{{environment}}-{{project}}-{{parameter}}"
  create_environments  = true
  create_projects      = true
}

resource "cloudtruth_azure_push_action" "push" {
  integration = cloudtruth_azure_integration.writable.name
  name        = "Push to Azure"
  description = "Push CloudTruth parameters to Azure Key Vault"

  resource           = "{{project}}-{{environment}}-{{parameter}}"
  coerce_parameters  = true
  include_parameters = true
  include_secrets    = true
  include_templates  = false

  projects = [cloudtruth_project.example.id]
}
```
